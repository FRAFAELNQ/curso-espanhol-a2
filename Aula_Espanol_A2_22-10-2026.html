Estar durante un periodo

También usamos estar + gerundio para un periodo alrededor de ahora, no solo para este momento.

🧠 Gramática

Gerundio regular
  • Verbos en -ar → -ando: hablar → hablando.
  • Verbos en -er / -ir → -iendo: comer → comiendo, vivir → viviendo.
Estoy desayunando.
Estamos compartiendo el libro.
Raíz acabada en vocal: -yendo
  • leer → leyendo
  • traer → trayendo
  • construir → construyendo
  • oír → oyendo
  • ir → yendo
La i entre dos vocales se convierte en y.
Irregulares e → i (-ir)
  • pedir → pidiendo
  • decir → diciendo
  • repetir → repitiendo
  • seguir → siguiendo
  • conseguir → consiguiendo
  • servir → sirviendo
  • reír → riendo
También cambian: sentir → sintiendo, venir → viniendo, mentir → mintiendo.
Irregulares o → u
  • dormir → durmiendo
  • morir → muriendo
  • poder → pudiendo
volver → volviendo es regular: no cambia la raíz.
Verbos reflexivos con estar + gerundio

El pronombre puede ir antes de estar o pegado al gerundio. Si va pegado, el gerundio lleva tilde.

Me estoy duchando. / Estoy duchándome.
Se está levantando. / Está levantándose.
Se están saludando. / Están saludándose.
Me estoy sintiendo mal. / Estoy sintiéndome mal.
La profesora dijo: estar + gerundio es como un matrimonio: no se puede separar. Entre estar y el gerundio no ponemos ninguna palabra, solo el pronombre pegado al final o delante de estar.
Presente o estar + gerundio
Normalmente desayuno a las ocho.
Ahora estoy desayunando.
Presente: costumbres y hechos habituales. Estar + gerundio: acciones en desarrollo, ahora o en este periodo.
